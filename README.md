# 🛍️ NovaCart Global - E-commerce Analytics Dashboard

## 📌 Project Overview

NovaCart Global is an end-to-end Business Intelligence dashboard built in Power BI to analyze e-commerce sales performance, customer behavior, product performance, and revenue trends.

The dashboard transforms raw transactional data into actionable business insights through interactive visualizations, KPI tracking, and dynamic filtering, helping stakeholders monitor business performance and make data-driven decisions.

---

## 🎯 Business Objective

The objective of this project is to:

- Monitor overall sales performance
- Analyze customer acquisition and demographics
- Evaluate product performance
- Track payment and revenue trends
- Identify business opportunities through interactive analytics

---

## 🛠️ Tools & Technologies

- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Interactive Slicers
- Business Intelligence Dashboard Design

---

## 📂 Dataset

This project uses a public e-commerce dataset consisting of customer, product, and transaction information.

**Tables Used**
- Customer
- Product
- Transactions

> **Note:** The raw dataset (CSV files) is not included in this repository because it originates from a publicly available dataset. The repository contains the complete Power BI dashboard (.pbix), exported report (.pdf), and dashboard screenshots.
